# Support

## Before opening an issue

1. Update to the latest published release.
2. Read the add-on documentation and changelog.
3. Check `/api/health` and `/api/ready`.
4. Search existing GitHub Issues for the same symptom.

## Requesting help

Open a GitHub Issue and include:

- Fitness Habit Tracker version
- Home Assistant version and installation type, or Docker version
- host architecture (`amd64` or `aarch64`)
- whether the problem occurs through ingress, direct access, or both
- concise reproduction steps and relevant log lines

Remove names, weights, database contents, access tokens, ingress paths, host
addresses, and other private household information before posting.

Use the private vulnerability-reporting path described in `SECURITY.md` for
security concerns rather than opening a public issue.
